# 訪問看護ステーション リハビリ責任者業務

訪問看護ステーションでリハビリ責任者として行う業務。以下6つのサブタスクがある。

## サブフォルダ構成

| フォルダ | 用途 |
|---|---|
| [利用者データ/](利用者データ/) | 利用者ごとの身体機能・精神機能・動作能力データ(定期収集した生データ) |
| [レポート/](レポート/) | 利用者ごとのグラフ入り資料(上司へ提出用) |
| [傾向分析/](傾向分析/) | 収集データ全体の傾向・集計分析 |
| [論文調査/](論文調査/) | 訪問リハビリ・高齢者身体機能・性格(BIG5)関連の論文まとめ |
| [発表資料/](発表資料/) | 傾向分析と論文調査を統合した定期発表用資料 |
| [議事録/](議事録/) | 定例ミーティングの議事録 |

## 進め方の目安

- **利用者データ**: 収集日・利用者ID・測定項目(身体機能/精神機能/動作能力)を明記して保存する。
- **レポート**: 利用者ごとに経時変化がひと目でわかるグラフ(折れ線推奨)+簡潔な所見を添える。
- **傾向分析**: 利用者横断で集計し、平均・分布・特筆すべき変化を記述する。
- **論文調査**: 検索キーワード例「訪問リハビリテーション」「高齢者 身体機能」「BIG5 性格特性 高齢者」。要約フォーマットはルートCLAUDE.mdの共通ルールに準拠。
- **発表資料**: 傾向分析+論文調査の知見を組み合わせ、上司・チーム向けに提示できる形にする。
- **議事録**: 日時・出席者・議題・決定事項・次回までのToDoを記載する。

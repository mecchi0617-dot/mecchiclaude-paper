# mecchiclaude-papers

[MecchiClaude](https://github.com/) ワークスペース(ローカルのみ、Git管理外)から、論文調査タスクだけを切り出したリポジトリです。クラウドの月次スケジュール実行(`/schedule`)がここに新しい論文調査ファイルをコミットします。

## このリポジトリができた経緯

MecchiClaudeの`01_訪問看護リハビリ業務/`フォルダには実際の利用者様の記録(氏名・年齢・健康状態など)が含まれており、それをクラウド環境に接続するのは避けたいという判断から、論文調査に必要な部分(CLAUDE.mdのキーワード一覧・論文調査フォルダの中身)だけをこちらに複製しました。作成日: 2026-08-18。

## 運用フロー

1. クラウドの月次ルーティンが、01/02/03それぞれのCLAUDE.mdに書かれたキーワードで新しい論文がないか確認し、既存ファイルと重複しない内容を`YYYYMMDD_キーワード.md`として各`論文調査/`フォルダにコミットする。
2. **ローカルのMecchiClaudeには自動反映されません。** ローカルでClaude Codeを開いたときに「mecchiclaude-papersリポジトリを同期して」と頼めば、新しいファイルを確認してMecchiClaudeの対応フォルダにコピーできます(その際、ローカルの`git pull`が必要です)。
3. 手動で同期する場合は、このリポジトリを`git pull`した上で、`01_訪問看護リハビリ業務/論文調査/`等の新しいファイルを`/Users/hayashiminoru/Desktop/MecchiClaude/`の対応フォルダにコピーしてください。

## 注意

- ここには利用者データ・レポート・議事録などの実データは一切含めない方針です。今後もこのリポジトリには論文調査に関するファイルのみを置いてください。
